# MGLG Android app

This Android Studio project loads the deployed MGLG website at:

`https://mygenerationlovesgod.site.je/`

## Open and run

1. In Android Studio, choose **Open** and select this `mglg-android` folder.
2. Allow Gradle to sync and install Android SDK 36 if prompted.
3. Choose an emulator or connected Android phone, then select **Run**.

The app keeps MGLG website links inside the app, opens external, email, phone, and WhatsApp links with Android's matching app, supports website file inputs such as profile-photo uploads, and requires HTTPS only.
