Place the built Android APK here as `mglg-android.apk` to enable the dashboard download button.

In Android Studio, build the APK from `mglg-android` using **Build > Build Bundle(s) / APK(s) > Build APK(s)**. Copy the generated debug APK from `mglg-android/app/build/outputs/apk/debug/app-debug.apk` into this folder and name it `mglg-android.apk`.
